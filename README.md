# Save and Earn 二手家具平台

可在手機與電腦使用的繁體中文二手家具平台互動原型。使用原生 HTML、CSS 與 JavaScript，無需安裝依賴。

## 本機使用

雙擊 `start-preview.cmd`，或在此目錄執行 `npm run dev`，保持啟動視窗開啟，再使用同一台電腦開啟 http://127.0.0.1:4173 。語法檢查：`npm run check`。業務邏輯測試：`npm test`。

`127.0.0.1` 僅供本機預覽；給別人看請使用部署後的公開網址。GitHub Pages 設定與分享方式見 [GITHUB_PAGES.md](GITHUB_PAGES.md)。

## 已實作

- 家具類型、關鍵字、地區、價格、商品狀況篩選及價格／上架順序排序。
- 商品詳情、收藏及空狀態。
- 照片驗證與縮圖、家具資料輸入、明確標示的規則估價、自訂售價與示範上架。
- 自行取貨或配送費用試算，包含地區、樓層、電梯及拆裝。
- 模擬下單、訂單紀錄，以及單筆訂單刪除與資料清除。
- 搬運預約畫面：選擇日期、台灣時間時段、示範取送地點與備註，保存預約資料。
- 配送與送達畫面：示意路線、配送進度、開始搬運、送達點交與紀錄明細。
- 收貨與撥款畫面：商品驗收清單、問題紀錄、暫停／恢復模擬撥款，以及含金額與時間的完成明細；實際付款永遠為 NT$ 0。
- 響應式介面、鍵盤操作、對話框與減少動畫設定。
- 全站加大字級：內文與表單以 16–18px 為主；以綠、暖橘、霧藍、奶油黃及淡紫區分商品與交易步驟。

資料僅存於本機瀏覽器的 localStorage；清除瀏覽資料會使紀錄消失。無伺服器資料庫、帳號或多使用者同步。

## 示範範圍

AI 影像辨識與歷史成交資料尚未串接。估價採類型參考新品價或使用者提供的原價，乘以狀況係數與年限折舊，再產生 ±15% 區間。品牌與照片不參與計算。

配送採示範費率，並非物流商報價。下單不會扣款、保管資金、預約配送或通知任何人。正式產品需另外建置後端、會員、真實 AI 與成交資料、第三方金流、物流商、權限及交易爭議處理。

所有預載商品資料均為情境範例，非真實出售邀約。照片來自 Unsplash，已存於 `dist/assets`；字型由 Google Fonts 提供。使用者照片不會上傳至這些服務。

## 驗證範圍

已通過 23 項 Node 自動化測試，涵蓋複合篩選、排序、收藏與儲存、估價、示範上架、運費、訂單與刪除；另驗證預約日期、配送點交、驗收、問題暫停、重複提交、零元實際扣款、舊訂單相容及儲存失敗。測試使用簡化的 DOM 邊界，並非瀏覽器端到端測試。此環境無可用瀏覽器連線，尚未進行桌面與手機的實際畫面檢查。

## 檔案

- `dist/index.html`：頁面與 SVG 圖示。
- `dist/styles.css`：響應式樣式。
- `dist/theme.css`：全站字級、色彩與手機版排版調整。
- `dist/app.js`：商品與互動邏輯。
- `dist/order-flow.js`、`dist/order-flow.css`：搬運、送達、收貨與模擬撥款的畫面及流程。
- `server.mjs`：本機預覽伺服器。
- `.openai/hosting.json`：Sites 專案與靜態部署設定。
